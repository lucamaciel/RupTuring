# 🚗 Ruptura 2026 — Desafios de Mobilidade Localiza

## 📌 Sobre o projeto

Este projeto foi desenvolvido para o **Ruptura 2026**, desafio de inovação da **Localiza**, com o objetivo de propor soluções estratégicas para problemas reais relacionados à mobilidade.

A Localiza&Co atua em diferentes frentes do ecossistema de mobilidade, incluindo aluguel de carros, carros por assinatura, venda de seminovos e soluções para motoristas de aplicativos.

O desafio apresentado propõe dois territórios de inovação:

1. ⚡ **Mobilidade elétrica**
2. 📱 **Engajamento digital no aplicativo Localiza Assinatura**

---

# 🎯 O Desafio

A proposta do Ruptura 2026 é mergulhar profundamente em um problema de negócio e desenvolver uma estratégia que seja:

- Viável de implementar;
- Relevante para o cliente;
- Relevante para o negócio;
- Baseada em dados;
- Capaz de gerar impacto real;
- Criativa, mas conectada à realidade.

A Localiza destaca que não busca apenas ideias criativas, mas soluções com **profundidade de diagnóstico, impacto, viabilidade, qualidade da jornada e criatividade com propósito**.

# ⚡ Case 1 — Mobilidade Elétrica

## A assinatura como porta de entrada para a mobilidade elétrica

### Contexto

Os carros elétricos deixaram de ser uma promessa e já estão presentes no mercado brasileiro, com aumento na variedade de modelos e no interesse dos consumidores.

Apesar disso, ainda existem barreiras importantes para a adoção de veículos elétricos, principalmente relacionadas a:

- 🔋 Autonomia;
- ⚡ Recarga;
- 💰 Custos;
- 🔧 Manutenção;
- 📉 Depreciação;
- 🔄 Revenda;
- 🏠 Infraestrutura de recarga.

O consumidor demonstra interesse pela tecnologia, mas muitas vezes esse interesse não se transforma em uma contratação.
